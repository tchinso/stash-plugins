# PotPlayer Play

Adds a compact **팟** button to each Stash scene-detail page. Its tooltip is **팟플레이어로 재생하기**. The button reads the scene's primary original file path from Stash and starts it with:

`C:\Program Files (x86)\DAUM\PotPlayer\PotPlayer.exe`

Reload plugins in Stash after adding or changing this plugin. The button only appears for scene pages that have an original video file.
